# Student Performance Report System

## About the Project
The Student Performance Report System is a Python-based project that helps generate an individual student's academic performance report using an Excel dataset.

It calculates the student's total marks, percentage, class rank, identifies the subject that needs improvement, and displays attendance details.

## Features
- Upload student dataset using Excel.
- Search for a student using their roll number.
- Calculate total marks and percentage.
- Generate class rank.
- Identify the subject requiring improvement.
- Display attendance percentage and status.
- Display sports grade.
- Generate an individual student performance report.

## Technologies Used
- Python
- Pandas
- Google Colab
- Microsoft Excel

## Dataset Requirements
The Excel dataset should contain the following columns:

- `Student_ID`
- `Student_Name`
- `Mathematics_Marks`
- `Physics_Marks`
- `Chemistry_Marks`
- `Attendance_%`
- `Sports_Grade`

## How to Run the Project

1. Open Google Colab.
2. Copy and paste the Python code into a code cell.
3. Run the program.
4. Upload the student dataset in Excel format.
5. Enter the student's roll number.
6. View the generated performance report.

## Installation

Install the required libraries:

```bash
pip install pandas openpyxl
```

## Project Objective
The main objective of this project is to simplify student performance analysis and make it easier to access individual academic records through an automated reporting system.
